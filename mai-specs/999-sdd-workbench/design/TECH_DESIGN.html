每个 Workspace 一个会话

查询只读取这个会话所属 Workspace 的目录。打开另一个 Workspace 会进入另一个会话。没有打开 Workspace 时，现有入口不创建会话。

调用路径 读取规则 结果 变更

route调用路径

打开 Workspace 会创建或复用那个 Workspace 的会话，并把路径写入会话头。打开另一个 Workspace 得到另一个会话。没有已打开的 Workspace 时，现有入口直接返回，不创建会话。

rule读取规则

get 和 ensure 在没有记录时返回 defaultDirectory，缺省是进程启动目录。新方法 recorded 原样返回 string | null。

拟议读取

recorded(session: Session): string | null {
  return this.workingDirectoryProjectionHandle.stateOf(session)
}

这是拟议代码。它不把空值换成启动目录。

folder结果

一次调用追加到当前会话的 tool/result。打开另一个 Workspace 后，新结果写在新会话里，原会话的结果保持不变。
